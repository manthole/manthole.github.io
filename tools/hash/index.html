À quoi ça sert ?

Vérifier qu'un fichier téléchargé n'a pas été modifié (en comparant avec l'empreinte publiée par l'éditeur), ou calculer l'empreinte d'un fichier suspect pour la rechercher dans une base comme VirusTotal sans avoir à l'envoyer.

MD5 et SHA-1 sont cassés pour la sécurité (on sait fabriquer des collisions), mais restent utilisés pour identifier des fichiers et des IOC. Pour vérifier l'intégrité, préfère SHA-256.

What is it for?

Checking that a download hasn't been tampered with (by comparing with the vendor's published hash), or hashing a suspicious file to look it up in a database like VirusTotal without uploading it.

MD5 and SHA-1 are broken for security (collisions can be crafted), but they are still used to identify files and IOCs. For integrity checks, prefer SHA-256.

¿Para qué sirve?

Comprobar que un archivo descargado no ha sido modificado (comparándolo con la huella publicada por el editor), o calcular la huella de un archivo sospechoso para buscarla en una base como VirusTotal sin tener que enviarlo.

MD5 y SHA-1 están rotos para la seguridad (se saben fabricar colisiones), pero se siguen usando para identificar archivos e IOC. Para comprobar la integridad, mejor SHA-256.

Para que serve?

Verificar que um ficheiro descarregado não foi modificado (comparando com a impressão digital publicada pelo editor), ou calcular a impressão digital de um ficheiro suspeito para a procurar numa base como o VirusTotal sem ter de o enviar.

MD5 e SHA-1 estão quebrados para segurança (sabe-se fabricar colisões), mas continuam a ser usados para identificar ficheiros e IOC. Para verificar a integridade, prefere SHA-256.

Wozu dient das?

Prüfen, ob eine heruntergeladene Datei verändert wurde (Vergleich mit dem vom Hersteller veröffentlichten Hash), oder den Hash einer verdächtigen Datei berechnen, um ihn in einer Datenbank wie VirusTotal zu suchen, ohne die Datei hochzuladen.

MD5 und SHA-1 sind für Sicherheitszwecke gebrochen (Kollisionen lassen sich erzeugen), werden aber weiter zur Identifizierung von Dateien und IOCs genutzt. Für Integritätsprüfungen nimm lieber SHA-256.
