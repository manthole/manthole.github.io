    À quoi ça sert ?

    Ces enregistrements DNS décident si n'importe qui peut envoyer un e-mail en se faisant passer pour ton domaine. Un domaine sans DMARC en reject ou quarantine est une cible facile pour le phishing et la fraude au président. C'est aussi utile pour vérifier le domaine d'un fournisseur avant de faire confiance à ses e-mails.

    Limites

    Les sélecteurs DKIM ne peuvent pas être listés : sans le bon nom (visible dans l'en-tête DKIM-Signature d'un message reçu), seuls les plus courants sont essayés. Le domaine parent est déterminé de façon approximative pour les suffixes rares. Les résultats reflètent le DNS au moment de la requête.

    What is it for?

    These DNS records decide whether anyone can send email pretending to be your domain. A domain without DMARC set to reject or quarantine is an easy target for phishing and CEO fraud. It is also handy to check a supplier's domain before trusting its emails.

    Limits

    DKIM selectors cannot be listed: without the right name (visible in the DKIM-Signature header of a received message), only the most common ones are tried. The parent domain is approximated for rare suffixes. Results reflect DNS at query time.

    ¿Para qué sirve?

    Estos registros DNS deciden si cualquiera puede enviar un correo haciéndose pasar por tu dominio. Un dominio sin DMARC en reject o quarantine es un blanco fácil para el phishing y el fraude del CEO. También sirve para comprobar el dominio de un proveedor antes de fiarse de sus correos.

    Límites

    Los selectores DKIM no se pueden listar: sin el nombre correcto (visible en el encabezado DKIM-Signature de un mensaje recibido), solo se prueban los más habituales. El dominio padre se determina de forma aproximada para los sufijos poco comunes. Los resultados reflejan el DNS en el momento de la consulta.

    Para que serve?

    Estes registos DNS decidem se qualquer pessoa pode enviar um e-mail fazendo-se passar pelo teu domínio. Um domínio sem DMARC em reject ou quarantine é um alvo fácil para o phishing e a fraude do CEO. Também serve para verificar o domínio de um fornecedor antes de confiar nos seus e-mails.

    Limites

    Os seletores DKIM não podem ser listados: sem o nome certo (visível no cabeçalho DKIM-Signature de uma mensagem recebida), só se experimentam os mais comuns. O domínio pai é determinado de forma aproximada para sufixos raros. Os resultados refletem o DNS no momento da consulta.

    Wofür ist das gut?

    Diese DNS-Einträge entscheiden, ob jeder beliebige E-Mails im Namen deiner Domain senden kann. Eine Domain ohne DMARC auf reject oder quarantine ist ein leichtes Ziel für Phishing und CEO-Fraud. Praktisch auch, um die Domain eines Lieferanten zu prüfen, bevor man seinen E-Mails vertraut.

    Grenzen

    DKIM-Selektoren lassen sich nicht auflisten: Ohne den richtigen Namen (sichtbar im Header DKIM-Signature einer empfangenen Nachricht) werden nur die gängigsten probiert. Die übergeordnete Domain wird bei seltenen Endungen näherungsweise bestimmt. Die Ergebnisse geben den DNS-Stand zum Zeitpunkt der Abfrage wieder.
