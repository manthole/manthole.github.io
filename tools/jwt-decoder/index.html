Pourquoi le décoder ici ?


Un JWT donne souvent accès à un compte ou à une API. Le coller dans un site qui l'envoie à un serveur revient à confier cet accès. Ici, le décodage se fait entièrement dans ton navigateur.






Why decode it here?


A JWT often grants access to an account or an API. Pasting it into a site that sends it to a server means handing over that access. Here, decoding happens entirely in your browser.






¿Por qué decodificarlo aquí?


Un JWT suele dar acceso a una cuenta o a una API. Pegarlo en un sitio que lo envía a un servidor equivale a confiarle ese acceso. Aquí, la decodificación se hace íntegramente en tu navegador.






Porquê descodificá-lo aqui?


Um JWT dá muitas vezes acesso a uma conta ou a uma API. Colá-lo num site que o envia para um servidor é confiar-lhe esse acesso. Aqui, a descodificação é feita inteiramente no teu navegador.






Warum hier dekodieren?


Ein JWT gewährt oft Zugriff auf ein Konto oder eine API. Es auf einer Seite einzufügen, die es an einen Server schickt, heißt, diesen Zugriff aus der Hand zu geben. Hier erfolgt die Dekodierung vollständig in deinem Browser.
