Comment ça marche ?


Chaque caractère est tiré avec crypto.getRandomValues, le générateur cryptographique du navigateur, en évitant le biais du modulo. Au moins un caractère de chaque famille cochée est garanti, puis l'ensemble est mélangé.


L'entropie indique la difficulté à deviner le mot de passe : au-delà de 80 bits, une attaque par force brute est hors de portée. Pour la plupart des comptes, 16 caractères tous types confondus suffisent largement, à condition d'utiliser un mot de passe différent par site, dans un gestionnaire de mots de passe.






How does it work?


Each character is drawn with crypto.getRandomValues, the browser's cryptographic generator, avoiding modulo bias. At least one character from each selected set is guaranteed, then the whole thing is shuffled.


Entropy tells you how hard the password is to guess: above 80 bits, brute force is out of reach. For most accounts, 16 mixed characters are plenty, as long as each site gets its own password, stored in a password manager.






¿Cómo funciona?


Cada carácter se sortea con crypto.getRandomValues, el generador criptográfico del navegador, evitando el sesgo del módulo. Se garantiza al menos un carácter de cada familia marcada y luego se mezcla el conjunto.


La entropía indica la dificultad de adivinar la contraseña: por encima de 80 bits, un ataque de fuerza bruta queda fuera de alcance. Para la mayoría de las cuentas, 16 caracteres de todo tipo bastan de sobra, siempre que uses una contraseña distinta por sitio, en un gestor de contraseñas.






Como funciona?


Cada carácter é sorteado com crypto.getRandomValues, o gerador criptográfico do navegador, evitando o enviesamento do módulo. É garantido pelo menos um carácter de cada família marcada e depois o conjunto é baralhado.


A entropia indica a dificuldade de adivinhar a palavra-passe: acima de 80 bits, um ataque de força bruta está fora de alcance. Para a maioria das contas, 16 caracteres de todos os tipos chegam perfeitamente, desde que uses uma palavra-passe diferente por site, num gestor de palavras-passe.






Wie funktioniert es?


Jedes Zeichen wird gezogen mit crypto.getRandomValues, dem kryptografischen Generator des Browsers, ohne Modulo-Verzerrung. Mindestens ein Zeichen jeder angehakten Klasse ist garantiert, danach wird alles gemischt.


Die Entropie gibt an, wie schwer das Passwort zu erraten ist: Ab 80 Bit ist ein Brute-Force-Angriff außer Reichweite. Für die meisten Konten reichen 16 gemischte Zeichen völlig aus – solange du pro Website ein anderes Passwort verwendest, in einem Passwort-Manager.
