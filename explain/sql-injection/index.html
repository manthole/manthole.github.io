L'utilisateur saisit un identifiant et un mot de passe. Ici, au lieu d'un nom, il tape admin' -- et n'importe quoi comme mot de passe. Pour l'instant, ce n'est qu'une chaîne de caractères.

The user enters a username and a password. Here, instead of a name, they type admin' -- and anything as the password. For now, it is just a string.

El usuario introduce un nombre y una contraseña. Aquí, en lugar de un nombre, escribe admin' -- y cualquier cosa como contraseña. Por ahora, solo es una cadena de caracteres.

O utilizador introduz um nome e uma palavra-passe. Aqui, em vez de um nome, escreve admin' -- e qualquer coisa como palavra-passe. Por enquanto, é só uma cadeia de caracteres.

Der Benutzer gibt Benutzernamen und Passwort ein. Hier tippt er statt eines Namens admin' -- und irgendetwas als Passwort. Noch ist das nur eine Zeichenkette.

L'application fabrique la requête en collant la saisie au milieu du texte SQL. Le résultat est une seule chaîne envoyée à la base : elle n'a aucun moyen de savoir quelle partie vient du développeur et laquelle vient de l'utilisateur.

The application builds the query by pasting the input into the middle of the SQL text. The result is a single string sent to the database: it has no way to know which part came from the developer and which from the user.

La aplicación fabrica la consulta pegando la entrada en medio del texto SQL. El resultado es una sola cadena enviada a la base: no tiene forma de saber qué parte viene del desarrollador y cuál del usuario.

A aplicação fabrica a consulta colando a entrada no meio do texto SQL. O resultado é uma única cadeia enviada à base: ela não tem forma de saber que parte vem do programador e que parte vem do utilizador.

Die Anwendung baut die Abfrage, indem sie die Eingabe mitten in den SQL-Text klebt. Das Ergebnis ist eine einzige Zeichenkette an die Datenbank: Sie kann nicht wissen, welcher Teil vom Entwickler und welcher vom Benutzer stammt.

L'apostrophe tapée par l'utilisateur ferme la chaîne ouverte par le développeur, et -- ouvre un commentaire SQL : tout ce qui suit, y compris AND password = '…', est ignoré. La requête devient simplement « donne-moi l'utilisateur admin ».

The quote typed by the user closes the string opened by the developer, and -- starts an SQL comment: everything after it, including AND password = '…', is ignored. The query simply becomes “give me the admin user”.

El apóstrofo que escribe el usuario cierra la cadena abierta por el desarrollador, y -- abre un comentario SQL: todo lo que sigue, incluido AND password = '…', se ignora. La consulta se convierte simplemente en «dame el usuario admin».

O apóstrofo escrito pelo utilizador fecha a cadeia aberta pelo programador, e -- abre um comentário SQL: tudo o que vem depois, incluindo AND password = '…', é ignorado. A consulta passa a ser simplesmente «dá-me o utilizador admin».

Das vom Benutzer getippte Anführungszeichen schließt die Zeichenkette, die der Entwickler geöffnet hat, und -- beginnt einen SQL-Kommentar: Alles danach, einschließlich AND password = '…', wird ignoriert. Die Abfrage lautet nun einfach „gib mir den Benutzer admin“.

L'impactThe impactEl impactoO impactoDie Auswirkung

L'application voit une ligne et en conclut que l'identifiant et le mot de passe étaient bons. Et le contournement de connexion n'est qu'un début : selon les droits du compte de base de données, une injection permet de lire toutes les tables, de modifier ou supprimer des données, parfois d'exécuter des commandes sur le serveur.

The application sees a row and concludes that the username and password were right. And the login bypass is only the start: depending on the database account's rights, an injection can read every table, modify or delete data, sometimes run commands on the server.

La aplicación ve una fila y concluye que el nombre y la contraseña eran correctos. Y saltarse el inicio de sesión es solo el principio: según los derechos de la cuenta de base de datos, una inyección permite leer todas las tablas, modificar o borrar datos y a veces ejecutar comandos en el servidor.

A aplicação vê uma linha e conclui que o nome e a palavra-passe estavam certos. E contornar o login é só o começo: conforme os direitos da conta da base de dados, uma injeção permite ler todas as tabelas, alterar ou apagar dados e por vezes executar comandos no servidor.

Die Anwendung sieht eine Zeile und folgert, dass Benutzername und Passwort stimmten. Und die Umgehung der Anmeldung ist nur der Anfang: Je nach Rechten des Datenbankkontos kann eine Injection alle Tabellen lesen, Daten ändern oder löschen, manchmal sogar Befehle auf dem Server ausführen.

La correctionThe fixLa correcciónA correçãoDie Behebung

Avec une requête préparée, l'application envoie d'abord la structure de la requête avec des emplacements (?), puis les valeurs à part. La base analyse la requête avant de voir les données : admin' -- n'est plus qu'un nom d'utilisateur bizarre, qui n'existe pas.

Ce n'est pas de l'échappement de caractères : c'est une séparation stricte entre le code et les données, ce qui rend l'injection impossible par construction.

With a prepared statement, the application first sends the query's structure with placeholders (?), then the values separately. The database parses the query before seeing the data: admin' -- is now just an odd username that doesn't exist.

This isn't character escaping: it is a strict separation between code and data, which makes injection impossible by design.

Con una consulta preparada, la aplicación envía primero la estructura de la consulta con marcadores (?) y después los valores por separado. La base analiza la consulta antes de ver los datos: admin' -- ya solo es un nombre de usuario raro que no existe.

No es escapar caracteres: es una separación estricta entre código y datos, que hace la inyección imposible por diseño.

Com uma consulta preparada, a aplicação envia primeiro a estrutura da consulta com marcadores (?) e depois os valores à parte. A base analisa a consulta antes de ver os dados: admin' -- passa a ser apenas um nome de utilizador estranho que não existe.

Não é escapar caracteres: é uma separação estrita entre código e dados, que torna a injeção impossível por construção.

Mit einem Prepared Statement sendet die Anwendung zuerst die Struktur der Abfrage mit Platzhaltern (?), danach die Werte getrennt. Die Datenbank analysiert die Abfrage, bevor sie die Daten sieht: admin' -- ist nur noch ein seltsamer Benutzername, den es nicht gibt.

Das ist kein Escapen von Zeichen, sondern eine strikte Trennung von Code und Daten – damit ist Injection konstruktionsbedingt unmöglich.
