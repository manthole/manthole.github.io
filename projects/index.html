Un VPN écrit de zéro en Go, sur le modèle de WireGuard.A VPN written from scratch in Go, modelled on WireGuard.

Le client et le serveur se mettent d'accord sur des clés de session en deux messages, puis chaque paquet IP voyage chiffré en UDP entre deux interfaces réseau virtuelles.

  • Poignée de main Noise IK (X25519, ChaCha20-Poly1305, BLAKE2s) : confidentialité persistante, identité du client chiffrée, serveur muet face aux clés inconnues.
  • Anti-rejeu : horodatage chiffré dans la poignée de main, fenêtre glissante de 2048 paquets (RFC 6479) pour les données.
  • Routage par clé : un client authentifié ne peut pas usurper l'adresse d'un autre.
  • Renouvellement des clés toutes les 2 minutes, sans couper le trafic.
  • Interface virtuelle native : utun sur macOS, /dev/net/tun sur Linux.

Testé comme on attaque : 13 tests automatiques, dont des attaques (poignée de main rejouée, paquet modifié d'un seul bit, client inconnu, usurpation d'adresse), et un test réel où une capture réseau vérifie qu'aucun contenu ne circule en clair. Ces tests ont révélé deux vrais bugs, corrigés avant publication.

Client and server agree on session keys in two messages, then every IP packet travels encrypted over UDP between two virtual network interfaces.

  • Noise IK handshake (X25519, ChaCha20-Poly1305, BLAKE2s): forward secrecy, encrypted client identity, a server that stays silent to unknown keys.
  • Anti-replay: encrypted timestamp in the handshake, 2048-packet sliding window (RFC 6479) for data.
  • Cryptokey routing: an authenticated client cannot spoof another client's address.
  • Key rotation every 2 minutes, without dropping traffic.
  • Native virtual interface: utun on macOS, /dev/net/tun on Linux.

Tested the way it would be attacked: 13 automated tests, including attacks (replayed handshake, single-bit tampering, unknown client, address spoofing), plus a real-interface test where a packet capture checks that nothing travels in clear text. These tests caught two real bugs, fixed before release.
